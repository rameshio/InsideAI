## What it does
This worksheet helps you plan a small retrieval workflow, from source documents to a checked answer.

## How to use it
Document the source, who may access it, its last review date, and a few test questions. For each answer, save the retrieved passages and check whether they support it.

## The workflow
Collect → prepare → retrieve → generate → cite → review.

<Callout>Use public, non-sensitive documents for your first prototype. Production systems need explicit access controls and document handling policies.</Callout>
