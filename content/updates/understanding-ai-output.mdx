  - headline: Plausible language is not a fact check
    happened: Language models generate text from patterns in context. A well-formed
      explanation can include incorrect details or unsupported citations.
    matters: Separating fluency from accuracy makes it easier to use an assistant
      productively without giving it more authority than its evidence supports.
    limitations: Error rates vary by model, task, and context. This edition does not
      report a benchmark or claim that all systems behave identically.
    sourceName: NIST Generative AI Profile
    sourceUrl: https://doi.org/10.6028/NIST.AI.600-1
  - headline: Grounding helps, but review still matters
    happened: Retrieval-augmented generation supplies external passages to a model
      at answer time. Those passages can give an answer more relevant context.
    matters: A document workflow can make evidence easier to inspect. Useful
      citations should point to the actual supporting passage.
    limitations: Retrieval can miss relevant text, and generation can still
      misinterpret it. Access permissions and source quality remain essential.
    sourceName: Original RAG research paper
    sourceUrl: https://arxiv.org/abs/2005.11401
